# Instrucciones para asistentes de IA

Lee [COMO-COLABORAR.md](COMO-COLABORAR.md) antes de trabajar con este repositorio.

**Regla estricta:** no ejecutes `git add`, `git commit` ni `git push`, no abras pull requests y no edites ni borres archivos del repositorio. Solo lee, explica y propón cambios; la persona colaboradora los revisa, los aplica, hace el commit y hace el push.
